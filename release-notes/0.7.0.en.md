## New

- Added a frame scrubber to the timeline. Click or drag to jump to any
  frame, and the playhead follows along during playback.
- Added a live wobble preview next to the wobble slider so you can see
  a line wiggling at the current strength while adjusting the value.
- You can now crop or expand the canvas area without scaling the
  artwork. Choose absolute or relative dimensions, a 3×3 anchor, and
  offsets.
- Added image resizing by exact pixel dimensions or percentage. It
  scales artwork and brush sizes, with an option to preserve the
  aspect ratio.
- A new action bar appears below the selection. Preview any combination
  of move, scale, rotate, and horizontal or vertical flips, then apply
  them together or cancel them; duplicate, delete, and deselect are
  available there too.
- Use `Ctrl/Cmd+1` for a true 100% actual-pixel view, or the logarithmic
  zoom slider in the status bar to choose any zoom from 1–1600%.

## Improved

- Dragging inside a selection no longer moves it immediately. Selected
  content moves only after you enable Move mode in the action bar.
- Improved preview rendering, document-setting changes, undo
  responsiveness, and memory use on large canvases and documents with
  many strokes.
- Bundled the Pretendard JP font and applied it across the interface.
- Moved the current color button from the bottom of the left rail to
  the top toolbar next to the recent colors, and the active color is
  now marked with a ring.
- Merged the current frame and total frame count into a single `1 / 30`
  control to remove duplicate frame displays from the timeline.
- On macOS, the title bar now blends into the application background.
- Added soft shadows to tool popovers and the canvas for more depth.
- Tool icons now wiggle briefly on hover.
- Added visible keyboard focus rings, and number fields now highlight
  on hover to show they are editable.
- When the wobble animation is turned off, the export menu now reads
  "Export image" instead of "Export current frame as image".
- Redesigned the release notes shown in the update window to match the
  new font and support dark mode.
