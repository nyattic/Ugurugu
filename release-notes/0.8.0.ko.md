## 개선

- 4K 대형 프로젝트에서도 영향을 받는 영역과 연산만 처리해 선 선택과
  편집이 빠르게 반응하도록 개선했습니다.
- 대형 프로젝트에 선을 추가할 때 증분 히스토리·직렬화 경로를 사용해
  처리 시간을 크게 줄였습니다.
- 프로젝트 점 개수 한도에 도달했을 때 선을 조용히 잘라내지 않고 결과를
  명확히 알립니다. 단순화된 선은 양 끝점을 보존합니다.
- 채우기 마스크, 변환된 선택 영역과 렌더링 픽셀이 같은 반투명 경계와
  일관된 이미지 샘플링을 사용하도록 통일했습니다.
- 단축키를 편집하거나 기본값으로 되돌려도 보조 단축키를 보존하고,
  보조 단축키와의 충돌도 검사합니다.
- 프레임과 레이어 컨트롤의 키보드·스크린리더 사용성을 개선했습니다.
- 스포이트가 알파 값을 보존하고, 최근 색상 설정 저장을 묶어서 처리하며,
  숨겨진 미리보기의 애니메이션 타이머를 중지합니다.

## 품질과 배포

- 경고를 오류로 처리하는 빌드, 코드 줄 커버리지 70% 기준, 번역 완성도
  검사, macOS·Windows 설치 패키지 스모크 테스트를 추가했습니다.
- 배포 빌드는 정확히 Qt 6.10.3을 사용하며, 릴리스 산출물에 빌드
  메타데이터와 SHA-256 체크섬 목록을 제공합니다.
- Windows 릴리스는 미서명이며 macOS 릴리스는 ad-hoc 서명만 사용하므로
  SmartScreen이나 Gatekeeper가 경고를 표시할 수 있습니다.
