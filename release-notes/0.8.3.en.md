## Fixed

- Strokes drawn with a tablet no longer taper abruptly at the end. A pen lift
  reports zero pressure, and applying that value to the final point collapsed
  the tip to the minimum width. The stroke now carries the last measured
  pressure through to its endpoint.

## Quality and distribution

- Windows builds now use the ClangCL toolset from Visual Studio 2026, and
  distribution builds use Qt 6.11.1. The minimum required Qt is still 6.10.
- Document, render, and UI tests are split into behaviour-scoped suites, and
  the format rules and preconditions the code cannot state on its own are now
  documented in the sources.
