## 수정

- 애니메이션 프레임 수가 많을 때 재생 중인 캔버스의 표시 해상도가
  지나치게 낮아지던 문제를 수정했습니다.
- 색상 추출 도구가 축소된 미리보기 대신 원본 해상도의 정확한 픽셀
  색상을 가져오도록 수정했습니다.
- 매우 가늘거나 긴 레이어의 썸네일 크기가 0이 되어 표시되지 않을 수
  있던 문제를 수정했습니다.
- 손상된 자동 복구 파일을 열지 못했을 때 파일이 삭제되던 문제를
  수정했습니다. 실패한 파일은 별도 경로에 남기고 그 위치를 안내합니다.

## 개선

- 높은 배율에서 화면 밖의 투명 배경까지 그리지 않도록 하고 프레임
  캐시를 조정해 캔버스 이동과 그리기 반응성을 개선했습니다.
- 미리보기, 레이어 썸네일과 애니메이션 내보내기의 메모리 사용량을
  제한하고, 내보내기가 끝나면 임시 캐시를 정리합니다.
- 정지된 레이어의 선택 영역 확인에서 같은 프레임을 반복 렌더링하지
  않도록 해 큰 문서의 선택 작업을 더 빠르게 처리합니다.
- 자동 업데이트 확인을 24시간에 한 번으로 제한해 앱을 실행할 때마다
  같은 업데이트 메타데이터를 다시 요청하지 않도록 했습니다.
- 복구, 렌더링, 내보내기와 빌드 구성을 기능별로 분리하고 테스트와
  배포 패키지 검증을 보강했습니다.
- 배포 패키지에 사용한 외부 라이브러리와 폰트의 라이선스 고지를
  포함했습니다.
