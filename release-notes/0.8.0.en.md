## Improved

- Selecting and editing strokes now stays responsive in large 4K projects by
  filtering work to the affected regions and operations.
- Adding strokes to large projects is substantially faster and uses an
  incremental history and serialization path.
- Reaching the project point limit now produces a clear result instead of
  silently truncating a stroke. Simplified strokes preserve both endpoints.
- Fill masks, transformed selections, and rendered pixels now use consistent
  half-opacity boundaries and deterministic image sampling.
- Shortcut customization preserves alternate shortcuts and detects conflicts
  with them.
- Frame and layer controls have improved keyboard and screen-reader support.
- The eyedropper preserves alpha, writes to recent-color settings are batched,
  and hidden previews no longer keep their animation timer running.

## Quality and distribution

- Added warnings-as-errors builds, a 70% line-coverage gate, translation
  completeness checks, and installed-package smoke tests for macOS and
  Windows.
- Distribution builds require exactly Qt 6.10.3. Release artifacts include
  build metadata and SHA-256 checksum manifests.
- Windows releases remain unsigned and macOS releases use an ad-hoc signature,
  so SmartScreen or Gatekeeper may display a warning.
