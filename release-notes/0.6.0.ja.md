## New

- 日本語インターフェースを追加しました。設定 → 言語で選択できる
  ほか、システム言語が日本語の場合は自動的に適用されます。
- ウォブルアニメーションをオフにするモードを追加しました。設定 →
  描画でオフにすると、通常のペイントツールとして使えます。
- ブラシにアンチエイリアスのオプションを追加しました。ドット風
  ではなく滑らかな線で描けます。
- 現在のフレームをJPGでも書き出せるようになりました。

## Improve

- GitHubリリースページにリリースノートが自動的に添付されるように
  なりました。
- アップデートのポップアップに、ユーザーの言語に合わせたリリース
  ノートが表示されます。
