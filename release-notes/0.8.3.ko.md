## 수정

- 타블렛으로 그린 선의 끝이 갑자기 가늘어지던 문제를 수정했습니다. 펜을
  떼는 순간에는 필압이 0으로 보고되는데, 이 값을 선의 마지막 점에 그대로
  적용하면서 끝부분이 최소 굵기로 뭉개졌습니다. 이제 직전에 실제로 측정된
  필압을 이어받아 자연스럽게 마무리됩니다.

## 품질과 배포

- Windows 빌드가 Visual Studio 2026의 ClangCL 도구 모음을 사용하며, 배포
  빌드는 Qt 6.11.1을 사용합니다. 빌드에 필요한 최소 Qt 버전은 6.10 그대로입니다.
- 문서·렌더·UI 테스트를 동작 단위로 나누고, 코드가 스스로 드러낼 수 없는
  형식 규약과 전제 조건을 소스에 명시했습니다.
