## New

- The canvas background colour can now be changed from **Edit → Canvas
  background…**. Lowering its opacity to zero makes the background fully
  transparent, which is what you want for sticker-style PNG and GIF output
  with no background behind the drawing.
- GIF export now offers a size and a transparency option. Pick anything from
  100% down to 25% and the dialog shows the resulting pixel size, and you can
  choose whether transparent areas stay transparent or are filled with white.

## Improved

- Updates are now checked every six hours instead of once a day, so a new
  version reaches you sooner.
- A check that fails because there is no connection is retried the next time
  the app starts. It previously had to wait for the full interval.
- Large canvases can be exported as GIF again. Export used to be blocked
  outright once it exceeded the memory limit, telling you to reduce the canvas
  size or frame count. The dialog now opens with the largest size that fits
  already selected, and shows how much memory the chosen size needs.
- Exporting a drawing with a transparent background as JPG now fills the
  transparent areas with white instead of black. JPG cannot store
  transparency.
