## 새 기능

- 타임라인에 프레임 스크러버를 추가했습니다. 클릭하거나 드래그해서
  원하는 프레임으로 바로 이동할 수 있고, 재생 중에는 현재 위치가
  표시됩니다.
- 우글거림 슬라이더 옆에 실시간 미리보기를 추가했습니다. 현재
  강도로 꿈틀거리는 선을 보면서 값을 조절할 수 있습니다.
- 그림 크기를 바꾸지 않고 캔버스 영역만 자르거나 확장할 수 있습니다.
  절대·상대 크기, 3×3 기준점과 오프셋을 지정할 수 있습니다.
- 정확한 픽셀 크기나 배율을 지정하고, 필요하면 가로세로 비율을 유지해
  그림과 브러시 크기를 함께 바꾸는 이미지 크기 변경 기능을 추가했습니다.
- 선택 영역 아래에 액션바가 표시됩니다. 이동, 크기 변경, 회전,
  좌우·상하 반전을 자유롭게 미리 본 뒤 한 번에 적용하거나 취소할 수
  있고, 복제·삭제·선택 해제도 바로 실행할 수 있습니다.
- `Ctrl/Cmd+1`로 실제 픽셀 100% 보기를 사용할 수 있고, 상태 표시줄의
  로그 줌 슬라이더에서 배율을 1~1600%로 조절할 수 있습니다.

## 개선

- 선택 영역 안을 드래그하면 바로 이동하던 동작을 없앴습니다. 액션바에서
  이동 모드를 켠 경우에만 선택 내용을 옮깁니다.
- 큰 캔버스의 화면 미리보기와 많은 스트로크가 있는 문서의 설정 변경,
  실행 취소 성능과 메모리 사용량을 개선했습니다.
- Pretendard JP 폰트를 내장해 모든 인터페이스 텍스트에 적용했습니다.
- 현재 색상 버튼을 왼쪽 아래에서 상단 툴바의 최근 색상 옆으로
  옮기고, 최근 색상에서 현재 색을 링으로 표시합니다.
- 현재 프레임과 전체 프레임 수를 `1 / 30` 형태로 합쳐 타임라인의
  중복 표시를 정리했습니다.
- macOS에서 제목 표시줄이 앱 배경과 자연스럽게 이어집니다.
- 도구 팝오버와 캔버스에 그림자를 더해 화면의 깊이감을 살렸습니다.
- 도구 아이콘에 마우스를 올리면 잠깐 꿈틀거립니다.
- 키보드 포커스가 보이도록 포커스 링을 추가하고, 숫자 입력 필드에
  호버 상태를 더해 편집할 수 있다는 것을 알기 쉽게 했습니다.
- 와글거림 애니메이션을 끈 상태에서는 이미지 내보내기 메뉴가
  "현재 프레임을 이미지로 내보내기" 대신 "이미지로 내보내기"로
  표시됩니다.
- 업데이트 알림에 표시되는 릴리즈 노트 디자인을 새 폰트와 다크
  모드에 맞게 다시 만들었습니다.
