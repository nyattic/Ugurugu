## Improved

- Long strokes on high-resolution canvases now update only the newly changed
  areas, and the completed preview is reused after pen-up for more responsive
  drawing.
- Zooming reuses the existing preview until input settles and then refreshes it
  once at full clarity. Panning repaints only the newly exposed edges.
- Selection move, scale, and rotation previews work on small regions, while
  content checks across up to 60 frames run in the background. Undoing a
  selection deletion now restores both the artwork and the selection.
- Image and GIF exports and layer thumbnails now run in the background. Exports
  report progress, can be canceled, and do not leave partial files behind.
- Layer-group rendering now reuses temporary images, and preview and export
  memory estimates include nested layer groups. Exports that would exceed the
  working-memory budget are stopped before rendering with guidance on reducing
  the requirement.
- Newly created layer groups can be nested up to eight levels. Documents from
  earlier versions that already exceed this limit still open with their
  structure preserved, and can be edited as long as their maximum nesting level
  is not increased.

## Reliability

- When unsaved work and a file to open are both found at startup, the app now
  offers to recover, preserve the recovery file, discard it, or cancel. Recovery
  files also carry their source and session identity to prevent the wrong
  project from being overwritten.
- Creating, opening, and recovering documents now use atomic transitions. If
  preparation fails, the current document, file path, undo history, and recovery
  file remain unchanged.
- A second app instance is blocked from changing the same recovery file at the
  same time.
