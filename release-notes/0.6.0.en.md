## New

- Added a Japanese interface. Choose it in Settings → Language, or it
  is applied automatically when your system language is Japanese.
- Added a wobble-off mode. Turn it off in Settings → Drawing to use
  the app as a regular drawing tool.
- Added a brush anti-aliasing option for smooth lines instead of
  pixel edges.
- The current frame can now be exported as JPG.

## Improve

- Release notes are now attached to GitHub releases automatically.
- The update popup shows release notes in your language.
