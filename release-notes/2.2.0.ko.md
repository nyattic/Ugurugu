## 개선

- 캔버스 화면 표시가 GPU를 사용합니다. 그림을 움직이거나 확대하고,
  애니메이션을 재생할 때 화면 전체를 CPU로 다시 늘려 그리지 않아 더
  부드럽게 반응합니다. GPU 가속을 사용할 수 없는 환경에서는 자동으로
  기존 소프트웨어 방식으로 전환됩니다.
- 미리 볼 프레임을 여러 개씩 준비하고, 메모리가 넉넉한 컴퓨터에서는 더
  많이 담아 둡니다. 선을 그린 뒤에는 모든 프레임을 처음부터 다시 만들지
  않고 바뀐 부분만 고쳐 그려서 재생이 더 빨리 매끄러워집니다.
- Windows에서 Wacom 드라이버의 WinTab 입력을 지원합니다. Wacom 펜의
  필압이 제대로 전달되지 않던 환경에서도 드라이버를 설치하면 필압을
  사용할 수 있습니다.
- 지우개 자국이 아래 그림과 겹치는 레이어도 보이던 모습 그대로 아래
  레이어와 합칠 수 있습니다. 합친 뒤 새로 지우면 합쳐진 그림 전체가
  지워집니다. 캔버스 크기를 바꾼 레이어처럼 모양을 지킬 수 없는 경우에는
  계속 합치지 않고 이유를 알려 줍니다.

## 수정

- 우글거림 재생을 껐을 때 레이어별 우글거림이 화면에서는 멈췄지만,
  스포이드로 집은 색이나 PNG·JPG로 내보낸 그림에는 움직인 위치가 반영되던
  문제를 고쳤습니다. 이제 화면에 보이는 모습과 같은 위치와 색을 사용합니다.
- 선이나 선택 영역을 그리는 도중 새 문서를 만들거나 다른 파일을 열면,
  펜을 뗄 때 그리던 내용이 새 문서에 들어가던 문제를 고쳤습니다. 문서가
  바뀌면 진행 중인 입력을 안전하게 취소합니다.
- 영역 선택을 그리다가 선택 방식이나 캔버스 크기가 바뀐 뒤 취소하면,
  그 전에 있던 선택이 사라지던 문제를 고쳤습니다.
- 복사한 선택 영역의 이동 상태가 남아 있다가 나중에 만든 다른 선택 영역을
  갑자기 이동 모드로 바꾸던 문제를 고쳤습니다.
- 프레임을 앞뒤로 넘겼을 때 선택 영역 안에 편집할 수 있는 선이 있는데도
  선 속성 편집이 꺼지거나, 반대로 편집할 선이 없는데 켜지던 문제를
  고쳤습니다.
- 선택 영역을 잇달아 바꿀 때 이전 선택을 확인하던 계산이 계속 쌓여 앱이
  느려질 수 있던 문제를 고쳤습니다. 필요 없어진 계산은 바로 취소합니다.
- 레이어 그룹이 깊게 겹친 애니메이션을 내보낼 때 필요한 메모리를 실제보다
  적게 계산하던 문제를 고쳤습니다. 내보내기 창은 문서 구조까지 고려해
  안전하게 처리할 수 있는 가장 큰 크기를 고릅니다.
- 자동 복구 저장이 겹쳐 진행될 때 이전 저장의 완료를 최신 저장의 완료로
  잘못 받아들여, 최신 복구 파일 저장이 실패해도 다시 시도하지 않던 문제를
  고쳤습니다.
- 내보내기, 자동 복구 저장, Windows 업데이트 확인의 백그라운드 작업에서
  예상하지 못한 오류가 나면 앱이 종료될 수 있던 문제를 고쳤습니다. 이제
  작업을 실패로 마무리하고 오류를 알리거나 다음 저장을 다시 시도합니다.
- 더 짧은 애니메이션을 열었을 때 캔버스는 유효한 프레임으로 이동했지만
  타임라인이 이전 프레임을 가리킬 수 있던 문제를 고쳤습니다.
