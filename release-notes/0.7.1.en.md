## Fixed

- Fixed the canvas becoming unnecessarily low-resolution during playback
  when an animation contains many frames.
- The color picker now samples the exact source-resolution pixel instead
  of a downscaled preview.
- Fixed thumbnails disappearing for extremely thin or wide layers when
  one calculated thumbnail dimension became zero.
- Unreadable recovery files are no longer deleted. A failed file is kept
  at a separate path, and the application shows where to find it.

## Improved

- Improved canvas responsiveness at high zoom by avoiding off-screen
  checkerboard drawing and tuning the frame cache.
- Bounded memory use for previews, layer thumbnails, and animation export,
  and clear temporary caches after an export completes.
- Selection checks on static layers no longer render the same frame
  repeatedly, improving selection performance in large documents.
- Automatic update checks are limited to once every 24 hours instead of
  requesting the same update metadata on every application launch.
- Split recovery, rendering, export, and build configuration into focused
  modules, with stronger tests and package validation.
- Distribution packages now include notices for bundled third-party
  libraries and fonts.
