## New

- Added an **About** tab to Settings where you can view the installed
  application version.
- Brush and eraser sizes can now be adjusted independently and retain
  their separate values when switching tools.
- The last-used tool, color, brush preset, per-preset brush sizes, eraser
  size, roughness, and anti-aliasing settings are now restored after
  restarting the app.
- You can now delete the final layer and leave a document with no layers,
  then add the first layer again with the `+` button.

## Fixed

- On macOS, the app now checks for a new update at launch when automatic
  checks are enabled.
- The macOS package now includes JPEG support, so JPG export works in the
  distributed application.
- Unfinished mouse and tablet interactions are now safely cancelled when
  the app or window loses focus.
- Spacebar panning no longer overrides the standard keyboard behavior of
  buttons, layer lists, and other controls.

## Improved

- Selection masks are deduplicated in project files to reduce file size
  and memory use while retaining compatibility with older projects.
- The unsaved-changes dialog now shows and supports `S` to save, `N` to
  discard, and `Esc` to cancel.
